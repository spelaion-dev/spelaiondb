# User guide

How to use SpelaionDB, one page per part of the app.

| Page | What it covers |
| --- | --- |
| [Adding connections](connections.md) | The connection form, passwords, SSH tunnels, Kubernetes, SQLite and DuckDB files, importing from other clients |
| [Sharing connections with a team](team.md) | Connections as files in git, repository trust, `${user.…}` variables, shared SSH host keys, `spelaiondb check` |
| [Schema explorer](explorer.md) | Objects by type, filters, generated SQL, table data tabs and editing data |
| [Running SQL](editor.md) | Running statements and scripts, placeholders, confirmations, keyboard shortcuts, tabs and `.sql` files |
| [Working with results](results.md) | Selecting, copying, exporting, sorting and filtering the grid, the cell viewer |
| [Saved queries and query history](saved-queries-and-history.md) | Saving SQL under a name, searching what ran |
| [For AI agents (MCP)](mcp.md) | What agents may do through `spelaiondb mcp`, and how to set it up |
| [Settings](settings.md) | Appearance, language, history, editor and automatic updates |

The newest features may be described only in the [release notes](../releases/) until their
page here catches up.
