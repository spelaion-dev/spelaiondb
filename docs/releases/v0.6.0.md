SpelaionDB 0.6.0 expands the explorer, adds network profiles with proxy support, and makes
lost database sessions visible.

## Explorer and SQL
- Create, rename and drop database objects from the explorer after reviewing the generated SQL.
  Add indexes and constraints, inspect table details, and generate SQL for selected objects.
- Bookmark objects, find them by name with Ctrl+Shift+D, link the explorer to the active editor,
  and set the editor's schema from the explorer.

## Connections and network profiles
- Reuse network profiles from Settings, including SOCKS5 and HTTP proxies, with or without SSH
  hops. DBeaver's SOCKS proxy settings can be imported.
- Configure SSH connection timeouts, keep-alives, and local ports or port ranges.
- Database keep-alives can preserve idle sessions. When a connection is lost, the tab shows the
  reason and offers to reconnect; reconnecting never reruns a query.

## Security and fixes
- Repository trust approvals are tied to the content reviewed, and changed SSH host keys remain
  blocking errors. PostgreSQL and MySQL metadata decoding has additional allocation limits.
- Several connection and test shutdown races have been fixed. Updates can be installed directly
  from Settings.

## Installing
- **Windows:** `SpelaionDB_0.6.0_x64-setup.exe` installs for the current user; an MSI is also
  available. Installers are not signed, so SmartScreen may warn.
- **macOS:** choose the Apple Silicon or Intel DMG. The app is not notarized; use right-click →
  Open the first time.
- **Linux:** choose the DEB, RPM or AppImage. Only the AppImage updates itself.
- **CLI / MCP server:** the `spelaiondb-*` archives contain the CLI binary.

Existing installations can update from the app's update notice.
