SpelaionDB 0.8.0 is about understanding and moving data: execution plans you can read on every
engine, data imported from files or the clipboard, foreign keys you can follow, and your
connections brought over from the client you used before.

## Execution plans
- Explain a query on PostgreSQL, MySQL, MariaDB, SQL Server, SQLite and DuckDB and read the plan
  as an overview, a tree with its metrics, a graph or the raw output, with findings that explain
  each problem a step shows.
- ANALYZE really runs the query, so it warns first and goes through the same confirmations and
  read-only refusal as running it. Engines without ANALYZE (SQLite) say so.
- Save a raw plan, open a saved one (including the `sqlite3` shell's QUERY PLAN drawing), and
  export the plan's table as CSV.

## Data
- Import CSV, TSV, JSON arrays and Markdown tables into a table, from a file or the clipboard
  (Ctrl+Alt+V), with a live preview of each column's detected type, a review of the SQL the core
  wrote, progress and cancel. Rows load through each engine's bulk path, with every value bound.
- Follow foreign keys in table data tabs: open the row a key points to, see the rows that point
  back in the side panel, and browse a References tab for every table.
- Numbers about the selection: count, distinct, NULLs, sum, average, median, minimum, maximum
  and mode of the selected cells. A table column's statistics are counted by the server with
  read-only queries, sampled on big tables.

## Editor
- A command palette (Ctrl+Shift+P) with every command and its shortcut, your connections,
  recent files and the objects the explorer has read.
- Autocompletion knows which tables are in scope, and suggests joins from foreign keys.
- Editor actions (comments, case, folding, select or copy the current statement, lines to a
  quoted list), snippets (`sel`, `ins`, `upd` then Tab), and font and SQL formatting preferences.
- History filters by status, database, dates and pins, and exports the matching SQL; saved
  queries can be organized in folders.

## Connections
- Import connections from DataGrip (and the other JetBrains IDEs), TablePlus, HeidiSQL, MySQL
  Workbench 8.0, pgAdmin and Beekeeper Studio, with their SSH tunnels, TLS settings and folders.
  Every import shows a preview, lets you skip, copy or replace a connection that already exists,
  and lists each setting it could not bring over. Passwords go to the system keychain, only when
  the client's own files allow it.
- Each connection can set up its sessions: a default schema, an isolation level and statements
  that run every time a session opens. PostgreSQL and DuckDB tabs get a schema picker.
- Move connections between folders by dragging them, and find them by name, tag, type, host or
  description, forgiving a typo.
- Every action on a connection is in its right-click menu (also from the keyboard), and "Save
  query history" moved to the connection's form.
- An optional pause before "Run anyway" in the confirmation of a risky statement.

## Fixes
- Schema reads made by the app no longer count as statements of an open transaction.
- EXPLAIN on a SQLite file opened on a server keeps its output as rows.
- The MCP server's library is updated for a security advisory about unbounded HTTP responses
  (RUSTSEC-2026-0462).

## Installing
- **Windows:** `SpelaionDB_0.8.0_x64-setup.exe` installs for the current user; an MSI is also
  available. Installers are not signed, so SmartScreen may warn.
- **macOS:** choose the Apple Silicon or Intel DMG. The app is not notarized; use right-click →
  Open the first time.
- **Linux:** choose the DEB, RPM or AppImage. Only the AppImage updates itself.
- **CLI / MCP server:** the `spelaiondb-*` archives contain the CLI binary.

Existing installations can update from the app's update notice.
