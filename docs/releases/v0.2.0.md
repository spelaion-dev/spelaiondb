SpelunkDB 0.2.0 brings your connections over from DBeaver and reaches databases that live
inside Kubernetes.

## Import from DBeaver
- "Import from DBeaver…" in the add connection dialog finds DBeaver's workspace (or a folder
  you choose) and lists its PostgreSQL, MySQL, MariaDB and SQLite connections.
- Folders, environments (DBeaver's connection types) and SSH tunnels come along: one
  SpelunkDB tunnel per bastion and user, shared by the connections that use it.
- The user names and passwords DBeaver saved are read from its credentials file. Passwords go
  to the system keychain only if you tick that option, and are asked when connecting
  otherwise; they are never written to a file. A name already taken gets ` (DBeaver)` added;
  nothing existing is overwritten.

## Kubernetes
- A new **Kubernetes** tab in the connection form, next to SSH: pick a context of your
  kubeconfig, a namespace, the resource type (service, pod or deployment), its name and its
  port. Every list is read from `kubectl` as you go; the resource's ports (a service's ports or
  its containers' ports) set the connection's port.
- SpelunkDB runs `kubectl port-forward` with your kubeconfig, so EKS, GKE, AKS or OIDC
  authentication works as in your terminal. `kubectl` must be installed.
- Connections to the same resource and port share one `kubectl`, stopped with the last one and
  when the app closes. If it exits (a pod restarted, credentials expired), the connection shows
  `kubectl`'s message and is not restarted on its own.
- A connection goes through Kubernetes or an SSH tunnel, not both. In the file it is a
  `[kubernetes]` section of the connection.

## Installing
- **Windows:** `SpelunkDB_0.2.0_x64-setup.exe` installs for the current user without admin
  rights; the `.msi` is there for managed machines. The installers are not signed yet, so
  SmartScreen may warn: "More info" → "Run anyway".
- **macOS:** the `.dmg` for Apple Silicon (`aarch64`) or Intel (`x64`). The app is not notarized
  yet: open it with right-click → Open the first time.
- **Linux:** `.deb`, `.rpm` or the AppImage.
- **CLI / MCP server:** the `spelunk-*` archives hold the `spelunk` binary.

This is still a preview: expect rough edges, and please report them.
