The first preview of SpelunkDB: an open-source desktop database client with first-class SSH
tunnels and a read-only MCP server for AI agents.

## Databases and connections
- PostgreSQL (with TLS), MySQL, MariaDB and SQLite.
- Connections as TOML files: in the repository (`.spelunk/`, shared through git) or personal.
  Passwords go to the system keychain, are asked every time or come from an environment
  variable; never to a file.
- SSH tunnels through any number of bastions (agent, key, password, keyboard-interactive);
  a changed host key always blocks.
- Add, edit and delete connections from the app; paste a connection URL; create a new SQLite
  database.

## Querying
- SQL editor with the engine's dialect and autocompletion. Ctrl+Enter runs the statement under
  the cursor, Ctrl+Shift+Enter the whole script; Shift+Alt+F formats.
- `:name` parameters, saved queries (Ctrl+S) and query history.
- Confirmation before DELETE/UPDATE without WHERE, DROP, TRUNCATE and writes on production.

## Results
- A fast canvas grid with results kept in the core: sort by header, filter rows by text or by
  column like SQLyog (`=`, `<>`, `LIKE`, `IS NULL`…), resize columns, jump to a column.
- Copy as TSV, CSV, JSON, SQL INSERT, Markdown or an `IN` list; export whole results to CSV, TSV,
  JSON, SQL or Markdown.
- Cell viewer (pretty JSON, hex dump of bytes, long text) and row view.

## Tables
- Schema explorer with exact row counts and generated SELECT/INSERT/UPDATE/DELETE.
- Table data tabs: server-side pages with WHERE and ORDER BY.
- Editing for tables with a primary key: cells, NULL, deleted and new rows, applied in one
  transaction where each change must touch exactly one row.

## For AI agents
- `spelunk mcp`: a read-only MCP server over stdio for the connections you expose, with a
  statement classifier, read-only transactions, limits and an append-only audit log. The
  `spelunk` binaries below include it.

## Installing
- **Windows:** `SpelunkDB_0.1.0_x64-setup.exe` installs for the current user without admin
  rights; the `.msi` is there for managed machines. The installers are not signed yet, so
  SmartScreen may warn: "More info" → "Run anyway".
- **macOS:** the `.dmg` for Apple Silicon (`aarch64`) or Intel (`x64`). The app is not notarized
  yet: open it with right-click → Open the first time.
- **Linux:** `.deb`, `.rpm` or the AppImage.
- **CLI / MCP server:** the `spelunk-*` archives hold the `spelunk` binary.

This is a preview (0.1.0): expect rough edges, and please report them.
