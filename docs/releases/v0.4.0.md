SpelaionDB 0.4.0 is the first public release. SpelunkDB has a new name, its home is now
[spelaion-dev/spelaiondb](https://github.com/spelaion-dev/spelaiondb), and from this version on
the app keeps itself up to date.

## A new name: SpelaionDB
SpelunkDB is now **SpelaionDB**, part of the [Spelaion](https://spelaion.dev) family (σπήλαιον
is Greek for "cave"). Nothing you have is lost (ADR-023):

- **Your settings, connections and history** are copied from the old personal folder the first
  time the new app starts. The old folder is left as it was, as a backup.
- **Saved passwords** are found in the system keychain under the old name and copied to the new
  one the first time they are used.
- **Repositories:** the folder is now called `.spelaion/`. A `.spelunk/` folder is still read in
  0.4, with a notice to rename it: `git mv .spelunk .spelaion`. Trusted repositories stay
  trusted.
- **The app installs alongside SpelunkDB:** uninstall the old one when you are ready.
- **The command line and MCP server** are now `spelaiondb` (`spelaiondb mcp`,
  `spelaiondb check`…). Set your AI tools up again, for example
  `claude mcp add spelaiondb -- spelaiondb mcp`.

## Automatic updates
SpelaionDB checks for a new version when it starts, which you can turn off in Settings →
Updates, and shows a notice. Updates are signed, and they are installed only when you click
"Install and restart"; your tabs come back with their SQL, not run. This is the first version
that updates itself: install it by hand once.

## Editing results and more
- **Edit query results:** a single-table result with a primary key can be edited in the grid
  or in the cell panel. Insert, duplicate, delete and revert rows, set NULL, then save
  everything in one transaction. Joins and other ambiguous results stay read-only, and which
  table a result writes to is decided by the server's own name resolution, never guessed.
- **Paging:** query results load page by page as you scroll, with a page size to choose and a
  count of all the rows.
- **Process monitor** for PostgreSQL, MySQL, MariaDB and SQL Server: see what runs on the
  server, filter it, refresh it automatically, and cancel a query or end a session after
  confirming it (never on read-only connections).
- **Editor:** duplicate lines, multiple cursors, rectangular selections and select occurrences,
  as in VS Code.
- Database logos in the explorer, and a friendlier first screen without connections.

## Installing
- **Windows:** `SpelaionDB_0.4.0_x64-setup.exe` installs for the current user without admin
  rights; the `.msi` is there for managed machines. The installers are not signed yet, so
  SmartScreen may warn: "More info" → "Run anyway".
- **macOS:** the `.dmg` for Apple Silicon (`aarch64`) or Intel (`x64`). The app is not notarized
  yet: open it with right-click → Open the first time.
- **Linux:** `.deb`, `.rpm` or the AppImage. Only the AppImage updates itself; `.deb` and `.rpm`
  installs are updated with the new package.
- **CLI / MCP server:** the `spelaiondb-*` archives hold the `spelaiondb` binary.

This is still a preview: expect rough edges, and please report them.
