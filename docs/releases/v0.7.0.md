SpelaionDB 0.7.0 is about working in it all day: transactions you control, exports that stream,
scripts that behave like a script runner, a connection test that says what failed, and an MCP
page that sets up AI clients in one click.

## Editor and results
- Turn auto-commit off per tab, then Commit or Roll back; a badge shows an open transaction, and
  closing, disconnecting or quitting with one open asks first. Smart commit switches to manual on
  the first write, and is on for Production.
- Scripts can stop, continue or ask on an error, with a statement timeout and a summary of what
  ran. SQL Server `PRINT` output and MySQL warnings appear with the statement, and an optional
  system notification says when a long run finishes in the background.
- Manage tabs: rename, duplicate, pin, reorder, switch with Ctrl+Tab, reopen the last closed one
  with Ctrl+Shift+T, and close several at once.
- Open and save `.sql` files, with a recent files list, and get your tabs back with their text
  after a restart or a crash. They come back disconnected and nothing runs on its own.
- Hide and freeze result columns, select like a spreadsheet, find in results, filter by a cell's
  value, and copy as HTML, column names or an IN list.
- Export without loading the whole result: a query, a table data tab with its filter, a
  selection or explorer tables stream straight to a file, with progress, cancel and CSV options
  (including escaping of spreadsheet formulas).

## Connections
- Connection types (Development, Test, Production and your own) show as badges and carry
  safeguards: confirm SQL execution, confirm data changes, close idle connections. No file can
  loosen Production.
- Give connections a description and tags, and filter the explorer by tag.
- Duplicate, copy and paste connections (secrets never go to the clipboard), change a
  connection's engine and keep its settings, and name new connections from a pattern.
- The connection test shows each step (proxy, each SSH hop, Kubernetes, database), the one that
  failed, a hint, and diagnostics you can copy with every secret redacted.

## MCP server
- A new MCP server page installs SpelaionDB in Claude Desktop, Claude Code, Codex, Cursor,
  Windsurf and Antigravity, showing the change before writing it, and lists every agent call.
- A single switch makes every agent read-only, and query rows can be sent as JSON or TOON.

## Linux and fixes
- Without a system keychain, passwords are asked when connecting instead of failing. The personal
  folder is now private on Linux and macOS.
- Several Linux fixes: the save dialog, file pickers, select boxes and the webview's context menu.
- The desktop UI follows written guidelines, with refined dialogs, focus handling and labels.

## Installing
- **Windows:** `SpelaionDB_0.7.0_x64-setup.exe` installs for the current user; an MSI is also
  available. Installers are not signed, so SmartScreen may warn.
- **macOS:** choose the Apple Silicon or Intel DMG. The app is not notarized; use right-click →
  Open the first time.
- **Linux:** choose the DEB, RPM or AppImage. Only the AppImage updates itself.
- **CLI / MCP server:** the `spelaiondb-*` archives contain the CLI binary.

Existing installations can update from the app's update notice.
